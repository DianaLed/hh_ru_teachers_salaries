Аналитика зарплат учителей на hh.ru
📌 Описание

Проект собирает вакансии учителей с сайта hh.ru
, сохраняет их в формате CSV и JSON, а затем анализирует уровень зарплат в Москве и Нижнем Новгороде.
В работе используется Python (requests, BeautifulSoup, pandas, matplotlib).

📂 Структура проекта

\nproject/\n│── data_csv/ # Вакансии в формате CSV\n│── data_json/ # Вакансии в формате JSON\n│── parser.py # Скрипт для парсинга hh.ru\n│── analysis.ipynb # Jupyter Notebook с аналитикой\n│── README.md # описание проекта\n\n\n## ⚙️ Функционал\n- Парсинг вакансий учителей с hh.ru (Москва и Нижний Новгород).\n- Сохранение результатов в CSV и JSON.\n- Анализ зарплат:\n - среднее значение (mean), мода и медиана;\n - расчёт с учётом налогов и без них;\n - влияние выбросов на средние показатели.\n- Визуализация зарплат (гистограммы, боксплоты и др.). \n\n## 📊 Результаты\n- Москва: зарплаты учителей в среднем выше, но сильнее выражены выбросы.\n- Нижний Новгород: распределение более «ровное», меньше экстремальных значений.\n- Разница в медиане даёт более честное сравнение, чем просто среднее.\n\n## 🚀 Запуск\n1. Клонировать проект:\n bash\n git clone <ссылка-на-репозиторий>\n cd project\n \n2. Установить зависимости:\n bash\n pip install -r requirements.txt\n \n3. Собрать данные:\n bash\n python parser.py\n \n4. Запустить аналитику в Jupyter Notebook:\n bash\n jupyter notebook analysis.ipynb\n \n\n## 📦 Используемые библиотеки\n- requests\n- beautifulsoup4\n- pandas\n- numpy\n- matplotlib / seaborn (для графиков)\n\n##
